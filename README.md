## 规则树
> 如果业务中规则复杂，或者需要决策引擎可以直接使用该工具
```shell
   ## 下载源码至本地
   git clone https://github.com/maoyCloudSun/design-responsibility.git
   cd design-responsibility
   mvn clean install -Dmaven.test.skip=true
```

## 使用
> pom中直接引用对应的依赖即可
```xml
<dependency>
    <groupId>com.duncan.tool.design</groupId>
    <artifactId>responsibility</artifactId>
    <version>1.0.0</version>
</dependency>
```
